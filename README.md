# 🐟 Fish Weight Prediction using Machine Learning

## 📌 Project Overview
This project predicts the weight of fish using machine learning regression techniques.

## 🚀 Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib
- Streamlit (Optional)

## 📂 Project Structure
- data/ → Dataset
- src/ → Training and prediction scripts
- notebooks/ → Jupyter Notebook
- app.py → Web app for prediction

## 📊 Model Used
Linear Regression

## 📈 Evaluation Metrics
- Mean Absolute Error (MAE)
- R² Score
